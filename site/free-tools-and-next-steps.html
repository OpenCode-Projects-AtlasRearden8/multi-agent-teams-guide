The free toolbox (what this book assumes)

Nothing in this book requires a paid plan. Free tiers limit message volume, not the method — and the method is the product. The companion Agents-and-MCP Handbook covers single-agent tool setup, including MCP, in the same plain-English register.

A gentle upgrade path

Do not adopt everything at once. Each rung assumes the one before:

  • Level 1 — the memo habit (one agent, team-shaped). Even alone, make every request to a single agent carry Done / Next / Watch out against a written kickoff. You will feel the quality jump without any new tooling.
  • Level 2 — two chats (worker + checker). Add a checker conversation with fresh eyes. This is the cheapest big win in the entire book; most of the quality in our worked projects came from this single split.
  • Level 3 — the shared folder. Files in, files out, one-writer-per-file, status lines. Your team now survives across days and tools.
  • Level 4 — role-named subagents. If you use an agentic tool, define the roles you already wrote. Rules and memos stay identical; only the plumbing changes.
  • Level 5 — automation (later, optional). Scripts or queue tools that relaunch a pipeline nightly. Only after a month of supervised use, and only for jobs that are boring and checkable.

Choosing roles for a new project (the two-minute recipe)

Answer, in writing, before opening any chat:

  • What is the one deliverable? (A file name and its definition of done.)
  • What are the kinds of work? (Usually: gather facts, produce words/numbers, check.)
  • Where can errors hurt real people, money, or trust? Those steps each get a checker.
  • Who owns which file? Assign ownership before assigning tasks.

Then write the kickoff, staff the chats, and run one pass before reading anything.

When to walk away from a tool

  • It hides what it does to your files, or moves them without telling you.
  • It cannot be interrupted easily (remember the kill-switch habit).
  • It makes the shared folder harder to read — the folder is the product.
  • Your cost or attention per result is worse than doing it yourself with Level 1.

There is no shame in the single-agent level; most projects live there comfortably.

Where to go next

  • Re-run Project A with your own garage shelf. The claim-map habit transfers to anything you sell.
  • Steal Project B's banned-claims list for any writing that must be true: landing pages, listings, class syllabi, RFP responses.
  • Run Project C's sorter-only mode on a low-energy week and notice that a five-minute team still beats a zero-minute guilt spiral.
  • Read the Agents-and-MCP Handbook when you want single agents wired to tools, files, and services — then come back and give each of those agents a role card.
  • Teach it forward: our style notes (plain English, step by step, never condescending) are yours to copy. If you build a team template that works, publish it; somebody's Tuesday needs it.

The guide's closing rule

A team of agents is just a filing system with opinions. Keep the filing system boring, keep each opinion narrow, keep yourself in the approval loop — and the team will out-work any one agent exactly when it matters.
